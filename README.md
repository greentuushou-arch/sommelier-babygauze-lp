# ベビー6重ガーゼタオルギフト 399円OFFクーポン特集ページ

赤ちゃんにやさしい6重ガーゼタオルギフトの新商品訴求ページです。8/1〜8/20限定、399円OFFクーポン配布キャンペーン。

## ファイル構成

```
index.html          … 特集ページ本体(HTML+CSS+JS、すべてこの1ファイルに含まれています)
images/
  header/            … ヘッダーのロゴ
  hero/               … ファーストビューのメインビジュアル
  sections/           … 説明ブロックの画像
  cards/               … POINTカード(横スライド)の画像
```

`index.html` を丸ごと(`images/` フォルダごと)サーバーにアップロードしてください。パスはすべて相対パスなので、どのディレクトリに置いても動作します。

## 設定済みの内容

- **クーポン取得URL**は設定済みです(いただいたURLを反映済み)。
  ```
  https://coupon.rakuten.co.jp/getCoupon?getkey=M09HVS1ER1FHLVpHQlItVlIwUg--&rt=
  ```
- **カウントダウン**は 2026年8月1日 0:00〜8月20日 23:59 に設定済みです。
  - 開催前:「キャンペーン開始まで あと○日○時間○分」
  - 開催中:「キャンペーン終了まで あと○日○時間○分○秒」(1秒ごとに更新)
  - 終了後:カウントダウンが非表示になり、クーポンボタンが自動的に無効化されます(「受付終了しました」表示)。

## 画像の差し替え方法

`images/` 配下の該当ファイルを**同じファイル名で上書き**するか、`index.html` 内の `<img src="...">` のパスを書き換えてください。

| 画像 | 用途 |
|---|---|
| `images/header/logo.svg` | ヘッダーのロゴ |
| `images/hero/001.jpg` | ファーストビューのメインビジュアル |
| `images/sections/002.jpg`〜`004.jpg` | 説明ブロックの画像 |
| `images/cards/card001.jpg`〜`card006.jpg` | POINTカード(横スライド)の画像 |

## 実装上のご注意

- **JavaScriptを使用しています。** カウントダウン、クーポンURLの一括設定、紙吹雪演出、カードスライダーなどにJSを使っています。JavaScriptが実行できない環境には設置できませんのでご留意ください。
- レスポンシブ対応済みで、スマホ表示を基準に作成し、768px以上でPC向けレイアウトに切り替わります。
- 見出し等のフォントに Google Fonts(Zen Maru Gothic / Noto Sans JP)を外部読み込みしています。インターネット接続がある環境であれば通常表示され、読み込めない場合は端末の標準フォントで表示されます。
